# 老王口才深度演练 · 320篇原话朗读库 (Speech Practice v3.0)

专为**户外散步、通勤走路、路上听读复诵**设计的沉浸式口才肌肉记忆训练工具。
全面检索老王（王振宇）数百万字文稿，剔除口癖杂音，打造 **320 篇** 高信噪比长篇原话讲稿（每篇可沉浸朗读 10~20 分钟），并全新支持**“他读一句我读一句”的路上跟读模式（Shadowing Mode）**！

---

## 🌟 核心功能亮点 (v3.0 路上跟读版)

### 1. 🎧 路上跟读模式（他读一句，我读一句）
- **双手脱把 · 眼睛不看手机**：走在路上戴耳机，系统使用清晰自然的语音引擎示范朗读一句短句（15~30字）。
- **柔和“叮”声转场**：朗读完毕响起轻脆温和的提示音，提醒你进入跟读复诵时间。
- **智能等长/多倍率留白**：根据系统读该句的实际耗时，自动留白相应时间（默认 1.2 倍充裕时间）供你张口复诵，留白结束后自动朗读下一句！
- **语速与留白精细微调**：
  - 语速档位：`0.8x`（沉稳品味） / `1.0x`（标准语速） / `1.2x`（流利挑战）；
  - 留白倍率：`1.0x`（等长留白） / `1.2x`（推荐，呼吸自如） / `1.5x`（充裕思考）。

### 2. 📱 全黑屏“口袋防误触模式”（Pocket Mode）
- 走路把手机放裤兜或大衣口袋时，一键开启全黑屏省电与防误触模式；
- 屏幕中央提供**大面积盲操区**：
  - 👆 **轻触屏幕任意处**：暂停 / 继续播放；
  - ✌️ **双击屏幕中央**：立刻重听本句；
- 掏出手机瞄一眼时，大字荧光色卡片高亮显示当前正在跟读的句子，并显示“当前第几句 / 总句数”。

### 3. 🎙️ 沉浸看读模式（Teleprompter）
- 适合在桌前或室内，支持 **14px ~ 30px 字号调节**；
- **自动向下平滑滚屏（三档调速）**；
- **正计时秒表与一键复制全文（3500字）**。

### 4. 📝 闭环复盘打卡与数据档案
- 演练结束自动带入实际用时（例如“路上跟读用时：14分20秒”）；
- 专门设立**“⚠️ 卡壳点记录”**与**“💡 深度感悟记录”**；
- 本地浏览器 `localStorage` 自动持久化保存，支持连续打卡天数战报与 JSON 导出备份。
