# 老王口才深度演练 · 原话长篇朗读库 (Speech Practice v2.0)

专为手机端与口才实战设计的**长篇原话朗读与打卡复盘应用**。
全面检索老王（王振宇）数百万字文稿，剔除口癖杂音与结巴，完整保留**原汁原味的思维流动、论证张力与生动案例**，打造每篇可沉浸朗读 **10~20 分钟（3,200~3,700字）** 的高信噪比主题讲稿。

---

## 🌟 核心升级特色 (v2.0)

1. **拒绝干瘪精简，保留原声力量**：
   - 绝非几十秒的干瘪鸡汤或总结纲要，而是完整还原老王面对复杂现实问题的**起承转合、层层剖析、真实故事与犀利原话**。
   - 彻底修复口语录音中的结巴、打蹦字与口误，排版呼吸分明，带结构化章节小标题，极适合持续 15 分钟深情朗读。
2. **多维标签（Tags）与细颗粒度分类双轨筛选**：
   - **标签维度**：
     - `🏷️ 定义类`：老王对成熟的定义、对人生合伙人的定义、对财富自由的定义、对新时代执行力的定义、对配得感的定义、对平庸的定义等。
     - `🏷️ 心法类`：情绪去孩童化、反脆弱底盘、强人哲学、认错脱敏、不争当天结果。
     - `🏷️ 底层逻辑类`：权责边界论、能量守恒与外溢、存档读档机制、代际独立。
     - `🏷️ 实战案例类`：恋爱笔记本80条经验、食堂餐巾纸事件、老婆生孩子代孕与优先级。
     - `🏷️ 方法论类`：AI架构师工作流、集小成闭环、减法原则。
   - **分类维度**：心智成熟与人生底色、亲密关系与家庭伦理、商业认知与财富自由、AI协作与新时代能力、自我管理与强人心法、两代关系与权责边界。
3. **沉浸式长篇提词朗读模式（Reader & Teleprompter）**：
   - **大字号自由调节**：14px ~ 30px 无级缩放，夜间纯黑高对比度护眼底色。
   - **自动平滑向下滚屏（Auto-Scroll）**：支持慢速/标准/稍快档位，手机立在桌面上，解放双手边看边讲。
   - **实时秒表正计时**：实时显示已朗读分钟数与进度。
4. **闭环式复盘打卡（卡壳点与感悟档案）**：
   - 自动带入本次朗读时长（如“演练用时：15分40秒”）。
   - 专门设立**“⚠️ 卡壳点/表达不顺畅的段落”**文本框，精准抓取自己在哪个逻辑转折点卡住了。
   - 设立**“💡 读完后的深度感悟”**文本框，沉淀认知内化成果。
   - 支持连续打卡天数与篇次战报。
5. **一键复制与本地离线**：
   - 每篇支持【📋 复制全文】（3500字一键复制到微信或备忘录）与【仅复制金句】。
   - 纯前端零后端，PWA 支持添加到手机主屏幕全屏运行，数据保存在本地 `localStorage`，支持一键 JSON 导出与恢复。

## 📱 手机端访问与部署指南

### 方式 1：电脑局域网极速预览（手机直接打开）
在电脑终端运行：
```bash
python -m http.server 8888 --directory D:\AIworkstationpps\speech-practice
```
手机连接同一 WiFi，打开 Safari 或 Chrome，输入 `http://[你的电脑IP]:8888` 即可即刻开始手机端沉浸朗读。
在 Safari 点击底部“分享”图标 -> 选择 **“添加到主屏幕”**，享受无地址栏原生 App 体验。

### 方式 2：Vercel 免费公网上线（随时随地微信访问）
1. 提交至 GitHub 仓库；
2. 在 Vercel 导入该仓库，框架选 Other，一键点击 Deploy；
3. 获得专属域名（如 `https://wang-speech.vercel.app`），手机随时随地打卡练习。
